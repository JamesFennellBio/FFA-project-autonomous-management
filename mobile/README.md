# Phone app (iOS + Android)

## What it does
- React Native (Expo) app, talks straight to the Pi hub over farm Wi-Fi
- Same encryption as the nodes
- Live readings, history, switch outputs, alerts, approve new nodes
- Recipes (if-this-then-that) built with Blockly blocks
- Hub stores + runs recipes → work with PC and phone off

## Layers
- `mobile/app`: Expo app (TypeScript), screens, Blockly editor in a WebView
- `mobile/native`: turbo module generated by uniffi-bindgen-react-native
- `mobile/core`: Rust; pairing, signed X25519 handshake, ChaCha20-Poly1305, UDP
- `hub-node/src/hub/app.rs`: hub answers the phone (UDP 7301)
- `hub-node/src/recipes.rs`: hub runs recipes
- All crypto in Rust (`crypto-sharecrate`), none in JavaScript
- Crypto notes: "Phone app" in `docs/CRYPTO_REVIEW.md`

## Test the hub side without a phone
- Hub + PC daemon running (main README)
- `cargo run -p ffa-mobile-core --example phone -- --hub 127.0.0.1:7301 --state /tmp/phone.json pair`
- Approve "Phone app" on the desktop Pairing page
- `cargo run -p ffa-mobile-core --example phone -- --hub 127.0.0.1:7301 --state /tmp/phone.json ask '{"type":"channels"}'`
- Request types: top of `hub-node/src/hub/app.rs`

## Requirements
- Node.js 20+, Rust
- Android: Android Studio + SDK + NDK (works on Linux)
- iOS: Mac + Xcode (can't build iOS on Linux)
- Needs a development build (native Rust module) → Expo Go won't work

## Build: Android
- `rustup target add aarch64-linux-android armv7-linux-androideabi x86_64-linux-android`
- `cargo install cargo-ndk`
- Set `ANDROID_NDK_HOME` (Android Studio → SDK Manager → SDK Tools → NDK)
- `cd mobile/native && npm install && npm run ubrn:android`
- Phone on USB (USB debugging on) or emulator
- `cd mobile/app && npm install && npx expo run:android`

## Build: iOS (Mac)
- `rustup target add aarch64-apple-ios aarch64-apple-ios-sim`
- `cd mobile/native && npm install && npm run ubrn:ios`
- `cd mobile/app && npm install && npx expo run:ios --device`
- Allow "Local Network" permission or it can't reach the hub

## After changing Rust (`mobile/core` / `crypto-sharecrate`)
- Re-run `npm run ubrn:android` / `ubrn:ios` in `mobile/native`, rebuild the app

## If ubrn complains about missing turbo-module files
- `mobile/native` only has the ubrn config + `package.json`; ubrn generates the rest
- Fallback: `cd mobile && npx create-react-native-library@latest ffa-hub-native-scaffold`
  - pick "Turbo module" with C++
  - copy `native/ubrn.config.yaml` in, set `rust.directory` to `../core`
  - point `ffa-hub-native` in `app/package.json` at the new folder

## Using it
- Same Wi-Fi as the hub
- Settings → hub IP (port 7301 default)
- Optional: paste hub public key (`hub-node fingerprint`) → refuses any other hub
- Pair with hub → approve "Phone app" on desktop → match fingerprints
- Live: tap a sensor → history; switch → set output
- Recipes: New recipe → drag blocks into when / do / otherwise; temperatures in °C
- Save → hub checks it again
- Pairing tab: approve nodes (PC must be on)
- Lost phone: unpair under Paired phones on desktop
