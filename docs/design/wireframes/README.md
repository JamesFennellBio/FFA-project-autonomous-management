# Wireframes (Phase 0)

These are the source files for the v2 wireframe canvas, published privately at
https://claude.ai/artifact/Wwf8AnDSxFmv24D5kx6T5W

- Each `*.dc.html` file is one screen.
- `canvas.json` is the canvas layout.
- The tokens and motion rules they use are in `../specs/farmlab-spec.md`.
- `app/ui/style/tokens.css` is built from that spec in Phase 4.
