Features

What it does

Any pin, any sensor

Each pin can be a switch, an output, an analog sensor or a DS18B20 thermometer. Set it in a config file.

LoRa and Wi-Fi

Wi-Fi near the buildings. LoRa (915 MHz) for fields too far for Wi-Fi.Wi-Fi inside the building. LoRa (915 MHz) for greenhouses and outbuildings.

Encrypted

Every packet is encrypted and signed. New keys every 10 messages or every hour.

Recipes

"If this, then that" rules made from blocks on your phone. The hub runs them.

Works offline

The hub keeps 30 days of data and keeps running rules without the PC or the internet.

Desktop and phone

Charts, alerts, controls and pairing on the desktop app. Live readings and recipes on iPhone and Android.
